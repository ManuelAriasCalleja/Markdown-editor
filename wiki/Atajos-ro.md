# Scurtături de tastatură

## Fișier

| Scurtătură | Acțiune |
|---|---|
| `Ctrl+N` | Nou |
| `Ctrl+O` | Deschide |
| `Ctrl+S` | Salvează |
| `Ctrl+Shift+S` | Salvează ca |
| `Ctrl+W` | Închide fila |
| `Ctrl+P` | Tipărește |
| `Ctrl+Q` | Ieșire |

## Editare

| Scurtătură | Acțiune |
|---|---|
| `Ctrl+Z` | Anulează |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Refă |
| `Ctrl+Shift+V` | Lipește ca text simplu |
| `Ctrl+Alt+V` | Lipește ca Markdown |
| `Ctrl+F` | Caută |
| `Ctrl+H` | Înlocuiește |

## Format

| Scurtătură | Acțiune |
|---|---|
| `Ctrl+B` | Îngroșat |
| `Ctrl+I` | Cursiv |
| `Ctrl+U` | Subliniat |
| `Ctrl+Shift+X` | Tăiat |
| `Ctrl+E` | Cod în linie |
| `Ctrl+K` | Legătură |
| `Ctrl+1` … `Ctrl+6` | Titluri H1–H6 |
| `Ctrl+Shift+U` | Listă cu marcatori |
| `Ctrl+Shift+O` | Listă numerotată |
| `Ctrl+Shift+T` | Listă de sarcini |
| `Ctrl+]` / `Ctrl+[` | Mărește / micșorează indentarea |
| `Ctrl+Shift+Q` | Citat |
| `Ctrl+Shift+K` | Bloc de cod |

## Inserare

| Scurtătură | Acțiune |
|---|---|
| `Ctrl+Shift+F` | Inserează formulă |
| `Ctrl+Shift+N` | Inserează notă de subsol |

## Vizualizare

| Scurtătură | Acțiune |
|---|---|
| `Ctrl+Shift+M` | Vizualizare sursă Markdown |
| `Ctrl+Shift+D` | Vizualizare divizată |
| `F11` | Mod fără distrageri (ESC pentru a ieși) |
| `F9` | Schiță |
| `Ctrl+G` | Mergi la titlu |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (de asemenea Ctrl + rotiță) |

## Ajutor

| Scurtătură | Acțiune |
|---|---|
| `F1` | Manual |
