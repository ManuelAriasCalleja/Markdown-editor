# 使用

## 打开与保存

- 新建（Ctrl+N）、打开（Ctrl+O）、保存（Ctrl+S）、另存为（Ctrl+Shift+S）。全部使用
  UTF-8。
- **标签页**：每个打开的文档占一个标签页，用 Ctrl+W 关闭。重新启动时会重新打开上次
  会话的标签页。
- **从模板新建**（文件 → 从模板新建）从一份现成的 Markdown 骨架开始。
- **打开最近的文件**列出你最近用过的文档。
- 你也可以把文件拖放到窗口上来打开它。
- 如果文件在 md-editor 之外被改动，程序会提醒你：没有未保存的更改时直接重新加载，
  有的话则先询问。

### Front matter

如果你的文档以 `---…---`（YAML）或 `+++…+++`（TOML）块开头，保存时会原样保留（它既
看不到也不参与编辑）。它用来存放 `title`、`lang` 之类的元数据，导出时会用到。

## 设置格式

使用格式菜单或工具栏。你不需要键入 Markdown 符号：编辑器会替你加上。

- 粗体（Ctrl+B）、斜体（Ctrl+I）、下划线（Ctrl+U）、删除线、行内代码、链接
  （Ctrl+K）。
- 标题 H1–H6（Ctrl+1 … Ctrl+6）。
- 项目符号列表、编号列表和任务列表，按 Enter 会自动接着列出下一项（在空白项上按
  Enter 则退出列表）。任务的复选框单击即可勾选。
- 引用和代码块。

全部快捷键见[键盘快捷键](Atajos-zh)。

## 编辑与转换文本

- **粘贴为纯文本**（Ctrl+Shift+V）或**粘贴为 Markdown**（Ctrl+Alt+V），后者会把剪贴板
  里的 HTML 转换成 Markdown。在选中的文字上粘贴网址会自动把它变成链接。
- **编辑 → 转换文本**：全部大写、全部小写、首字母大写、行排序，以及智能排版（转换
  `--`、`---`、`...` 和直引号）。

## 插入

- 链接和图片（路径相对于文档，以便整体搬动）。
- **粘贴图片**：剪贴板里的图片会以 PNG 保存在你的 `.md` 旁边，并作为 `![](路径)`
  插入。拖到编辑器上或直接粘贴同样有效。
- 表格、水平分隔线、目录 (TOC) 和公式（Ctrl+Shift+F）。
- **脚注**（Ctrl+Shift+N）：插入引用标记 `[^n]` 及其定义。
- **警示块**：醒目的提示块（注意、提示、重要、警告、小心）。
- **特殊符号**以及**日期／日期和时间**。

## 表格

把光标放在表格内，表格菜单就可以增删行列，并设置每一列的对齐方式（左／中／右）。
对齐方式在保存时会保留下来。

## 公式

用插入 → 公式（Ctrl+Shift+F）插入行内（`$...$`）或块级（`$$...$$`）的 TeX 公式，并带
实时预览。双击公式即可编辑。它们以真正的二维方式绘制（分式、根式、矩阵、带上下限的
求和…）。更多细节见[功能特性](Caracteristicas-zh#tex-公式)。

## 图表

写一个语言为 `mermaid` 或 `plantuml` 的代码块；如果装有相应的工具（`mmdc` /
`plantuml`），它就会在块下方渲染为图片。如果没装，你会看到安装它的命令。

## 拼写检查

在视图 → 拼写检查中开启（需要 Hunspell）。语言依据文档自动选择，也可以在视图 →
拼写检查语言中手动指定。在带下划线的单词上单击右键会给出建议，并可以把它加入个人
词典。

## 视图模式

- **所见即所得**（默认）：只显示渲染后的结果。
- **源代码**（Ctrl+Shift+M）：全屏显示原始 Markdown。
- **分屏视图**（Ctrl+Shift+D）：渲染结果和源代码并排，保持同步。
- **大纲**（F9）和**跳转到标题**（Ctrl+G），用来在文档中导航。

## 查找与替换

Ctrl+F 查找，Ctrl+H 替换。支持上一个／下一个、全部替换和区分大小写。

## 导出与打印

文件 → 导出提供 PDF、HTML、ODF (.odt)、DOCX (.docx)、LaTeX (.tex) 和 EPUB (.epub)；
还有打印预览和打印（Ctrl+P）。导出为 ODF、DOCX 和 LaTeX 时会嵌入文档语言。

## 自动恢复

md-editor 每隔几秒就会保存一份草稿。如果程序异常退出，重新打开时会提示你恢复当时正在
写的内容。
