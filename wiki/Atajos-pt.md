# Atalhos de teclado

## Arquivo

| Atalho | Ação |
|---|---|
| `Ctrl+N` | Novo |
| `Ctrl+O` | Abrir |
| `Ctrl+S` | Salvar |
| `Ctrl+Shift+S` | Salvar como |
| `Ctrl+P` | Imprimir |
| `Ctrl+Q` | Sair |

## Edição

| Atalho | Ação |
|---|---|
| `Ctrl+Z` | Desfazer |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Refazer |
| `Ctrl+F` | Localizar |
| `Ctrl+H` | Substituir |

## Formatar

| Atalho | Ação |
|---|---|
| `Ctrl+B` | Negrito |
| `Ctrl+I` | Itálico |
| `Ctrl+U` | Sublinhado |
| `Ctrl+Shift+X` | Tachado |
| `Ctrl+E` | Código em linha |
| `Ctrl+K` | Link |
| `Ctrl+1` … `Ctrl+6` | Títulos H1–H6 |
| `Ctrl+Shift+U` | Lista com marcadores |
| `Ctrl+Shift+O` | Lista numerada |
| `Ctrl+Shift+T` | Lista de tarefas |
| `Ctrl+]` / `Ctrl+[` | Aumentar / diminuir recuo |
| `Ctrl+Shift+Q` | Citação |
| `Ctrl+Shift+K` | Bloco de código |

## Inserir

| Atalho | Ação |
|---|---|
| `Ctrl+Shift+F` | Inserir fórmula |

## Exibir

| Atalho | Ação |
|---|---|
| `Ctrl+Shift+M` | Vista de código-fonte |
| `Ctrl+Shift+D` | Vista dividida |
| `F11` | Modo sem distrações (ESC para sair) |
| `F9` | Estrutura |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (também Ctrl + roda) |

## Ajuda

| Atalho | Ação |
|---|---|
| `F1` | Manual |
