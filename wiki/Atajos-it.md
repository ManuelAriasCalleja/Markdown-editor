# Scorciatoie da tastiera

## File

| Scorciatoia | Azione |
|---|---|
| `Ctrl+N` | Nuovo |
| `Ctrl+O` | Apri |
| `Ctrl+S` | Salva |
| `Ctrl+Shift+S` | Salva con nome |
| `Ctrl+P` | Stampa |
| `Ctrl+Q` | Esci |

## Modifica

| Scorciatoia | Azione |
|---|---|
| `Ctrl+Z` | Annulla |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Ripeti |
| `Ctrl+F` | Trova |
| `Ctrl+H` | Sostituisci |

## Formato

| Scorciatoia | Azione |
|---|---|
| `Ctrl+B` | Grassetto |
| `Ctrl+I` | Corsivo |
| `Ctrl+U` | Sottolineato |
| `Ctrl+Shift+X` | Barrato |
| `Ctrl+E` | Codice inline |
| `Ctrl+K` | Collegamento |
| `Ctrl+1` … `Ctrl+6` | Intestazioni H1–H6 |
| `Ctrl+Shift+U` | Elenco puntato |
| `Ctrl+Shift+O` | Elenco numerato |
| `Ctrl+Shift+T` | Elenco attività |
| `Ctrl+]` / `Ctrl+[` | Aumenta / riduci rientro |
| `Ctrl+Shift+Q` | Citazione |
| `Ctrl+Shift+K` | Blocco di codice |

## Inserisci

| Scorciatoia | Azione |
|---|---|
| `Ctrl+Shift+F` | Inserisci formula |

## Visualizza

| Scorciatoia | Azione |
|---|---|
| `Ctrl+Shift+M` | Vista sorgente |
| `Ctrl+Shift+D` | Vista divisa |
| `F11` | Modalità senza distrazioni (ESC per uscire) |
| `F9` | Struttura |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (anche Ctrl + rotellina) |

## Aiuto

| Scorciatoia | Azione |
|---|---|
| `F1` | Manuale |
