# Tastenkürzel

## Datei

| Tastenkürzel | Aktion |
|---|---|
| `Ctrl+N` | Neu |
| `Ctrl+O` | Öffnen |
| `Ctrl+S` | Speichern |
| `Ctrl+Shift+S` | Speichern unter |
| `Ctrl+P` | Drucken |
| `Ctrl+Q` | Beenden |

## Bearbeiten

| Tastenkürzel | Aktion |
|---|---|
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Wiederholen |
| `Ctrl+F` | Suchen |
| `Ctrl+H` | Ersetzen |

## Format

| Tastenkürzel | Aktion |
|---|---|
| `Ctrl+B` | Fett |
| `Ctrl+I` | Kursiv |
| `Ctrl+U` | Unterstrichen |
| `Ctrl+Shift+X` | Durchgestrichen |
| `Ctrl+E` | Inline-Code |
| `Ctrl+K` | Link |
| `Ctrl+1` … `Ctrl+6` | Überschriften H1–H6 |
| `Ctrl+Shift+U` | Aufzählungsliste |
| `Ctrl+Shift+O` | Nummerierte Liste |
| `Ctrl+Shift+T` | Aufgabenliste |
| `Ctrl+]` / `Ctrl+[` | Einzug vergrößern / verkleinern |
| `Ctrl+Shift+Q` | Zitat |
| `Ctrl+Shift+K` | Codeblock |

## Einfügen

| Tastenkürzel | Aktion |
|---|---|
| `Ctrl+Shift+F` | Formel einfügen |

## Ansicht

| Tastenkürzel | Aktion |
|---|---|
| `Ctrl+Shift+M` | Markdown-Quelltext |
| `Ctrl+Shift+D` | Geteilte Ansicht |
| `F11` | Ablenkungsfreier Modus (ESC zum Verlassen) |
| `F9` | Gliederung |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (auch Ctrl + Mausrad) |

## Hilfe

| Tastenkürzel | Aktion |
|---|---|
| `F1` | Handbuch |
