# Sneltoetsen

## Bestand

| Sneltoets | Actie |
|---|---|
| `Ctrl+N` | Nieuw |
| `Ctrl+O` | Openen |
| `Ctrl+S` | Opslaan |
| `Ctrl+Shift+S` | Opslaan als |
| `Ctrl+P` | Afdrukken |
| `Ctrl+Q` | Afsluiten |

## Bewerken

| Sneltoets | Actie |
|---|---|
| `Ctrl+Z` | Ongedaan maken |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Opnieuw |
| `Ctrl+F` | Zoeken |
| `Ctrl+H` | Vervangen |

| Sneltoets | Actie |
|---|---|

| `Ctrl+I` | Cursief |
| `Ctrl+U` | Onderstrepen |
| `Ctrl+Shift+X` | Doorhalen |

| `Ctrl+K` | Koppeling |

| `Ctrl+Shift+O` | Genummerde lijst |
