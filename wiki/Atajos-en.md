# Keyboard shortcuts

## File

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New |
| `Ctrl+O` | Open |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+P` | Print |
| `Ctrl+Q` | Quit |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `Ctrl+F` | Find |
| `Ctrl+H` | Replace |

## Format

| Shortcut | Action |
|---|---|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+U` | Underline |
| `Ctrl+Shift+X` | Strikethrough |
| `Ctrl+E` | Inline code |
| `Ctrl+K` | Link |
| `Ctrl+1` … `Ctrl+6` | Headings H1–H6 |
| `Ctrl+Shift+U` | Bulleted list |
| `Ctrl+Shift+O` | Numbered list |
| `Ctrl+Shift+T` | Task list |
| `Ctrl+]` / `Ctrl+[` | Increase / decrease indent |
| `Ctrl+Shift+Q` | Quote |
| `Ctrl+Shift+K` | Code block |

## Insert

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+F` | Insert formula |

## View

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+M` | Markdown source view |
| `Ctrl+Shift+D` | Split view |
| `F11` | Distraction-free mode (ESC to exit) |
| `F9` | Outline |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (also Ctrl + wheel) |

## Help

| Shortcut | Action |
|---|---|
| `F1` | Manual |
