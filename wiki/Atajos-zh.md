# 键盘快捷键

## 文件

| 快捷键 | 操作 |
|---|---|
| `Ctrl+N` | 新建 |
| `Ctrl+O` | 打开 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+W` | 关闭标签页 |
| `Ctrl+P` | 打印 |
| `Ctrl+Q` | 退出 |

## 编辑

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+Shift+V` | 粘贴为纯文本 |
| `Ctrl+Alt+V` | 粘贴为 Markdown |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |

## 格式

| 快捷键 | 操作 |
|---|---|
| `Ctrl+B` | 粗体 |
| `Ctrl+I` | 斜体 |
| `Ctrl+U` | 下划线 |
| `Ctrl+Shift+X` | 删除线 |
| `Ctrl+E` | 行内代码 |
| `Ctrl+K` | 链接 |
| `Ctrl+1` … `Ctrl+6` | 标题 H1–H6 |
| `Ctrl+Shift+U` | 项目符号列表 |
| `Ctrl+Shift+O` | 编号列表 |
| `Ctrl+Shift+T` | 任务列表 |
| `Ctrl+]` / `Ctrl+[` | 增加／减少缩进 |
| `Ctrl+Shift+Q` | 引用 |
| `Ctrl+Shift+K` | 代码块 |

## 插入

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Shift+F` | 插入公式 |
| `Ctrl+Shift+N` | 插入脚注 |

## 视图

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Shift+M` | 源代码视图 |
| `Ctrl+Shift+D` | 分屏视图 |
| `F11` | 无干扰模式（按 Esc 退出） |
| `F9` | 大纲 |
| `Ctrl+G` | 跳转到标题 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 缩放（也可用 Ctrl+鼠标滚轮） |

## 帮助

| 快捷键 | 操作 |
|---|---|
| `F1` | 手册 |
