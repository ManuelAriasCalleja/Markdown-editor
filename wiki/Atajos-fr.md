# Raccourcis clavier

## Fichier

| Raccourci | Action |
|---|---|
| `Ctrl+N` | Nouveau |
| `Ctrl+O` | Ouvrir |
| `Ctrl+S` | Enregistrer |
| `Ctrl+Shift+S` | Enregistrer sous |
| `Ctrl+W` | Fermer l'onglet |
| `Ctrl+P` | Imprimer |
| `Ctrl+Q` | Quitter |

## Édition

| Raccourci | Action |
|---|---|
| `Ctrl+Z` | Annuler |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Rétablir |
| `Ctrl+Shift+V` | Coller comme texte brut |
| `Ctrl+Alt+V` | Coller comme Markdown |
| `Ctrl+F` | Rechercher |
| `Ctrl+H` | Remplacer |

## Format

| Raccourci | Action |
|---|---|
| `Ctrl+B` | Gras |
| `Ctrl+I` | Italique |
| `Ctrl+U` | Souligné |
| `Ctrl+Shift+X` | Barré |
| `Ctrl+E` | Code en ligne |
| `Ctrl+K` | Lien |
| `Ctrl+1` … `Ctrl+6` | Titres H1–H6 |
| `Ctrl+Shift+U` | Liste à puces |
| `Ctrl+Shift+O` | Liste numérotée |
| `Ctrl+Shift+T` | Liste de tâches |
| `Ctrl+]` / `Ctrl+[` | Augmenter / diminuer le retrait |
| `Ctrl+Shift+Q` | Citation |
| `Ctrl+Shift+K` | Bloc de code |

## Insertion

| Raccourci | Action |
|---|---|
| `Ctrl+Shift+F` | Insérer une formule |
| `Ctrl+Shift+N` | Insérer une note de bas de page |

## Affichage

| Raccourci | Action |
|---|---|
| `Ctrl+Shift+M` | Source Markdown |
| `Ctrl+Shift+D` | Vue divisée |
| `F11` | Mode sans distraction (ESC pour sortir) |
| `F9` | Plan |
| `Ctrl+G` | Aller au titre |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom (aussi Ctrl + molette) |

## Aide

| Raccourci | Action |
|---|---|
| `F1` | Manuel |
