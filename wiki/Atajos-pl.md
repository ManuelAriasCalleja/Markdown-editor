# Skróty klawiszowe

## Plik

| Skrót | Działanie |
|---|---|
| `Ctrl+N` | Nowy |
| `Ctrl+O` | Otwórz |
| `Ctrl+S` | Zapisz |
| `Ctrl+Shift+S` | Zapisz jako |
| `Ctrl+P` | Drukowanie |
| `Ctrl+Q` | Zakończ |

## Edycja

| Skrót | Działanie |
|---|---|
| `Ctrl+Z` | Cofnij |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Ponów |
| `Ctrl+F` | Znajdź |
| `Ctrl+H` | Zamień |

## Format

| Skrót | Działanie |
|---|---|
| `Ctrl+B` | Pogrubienie |
| `Ctrl+I` | Kursywa |
| `Ctrl+U` | Podkreślenie |
| `Ctrl+Shift+X` | Przekreślenie |
| `Ctrl+E` | Kod w wierszu |
| `Ctrl+K` | Odnośnik |
| `Ctrl+1` … `Ctrl+6` | Nagłówki H1–H6 |
| `Ctrl+Shift+U` | Lista wypunktowana |
| `Ctrl+Shift+O` | Lista numerowana |
| `Ctrl+Shift+T` | Lista zadań |
| `Ctrl+]` / `Ctrl+[` | Zwiększ / zmniejsz wcięcie |
| `Ctrl+Shift+Q` | Cytat |
| `Ctrl+Shift+K` | Blok kodu |

## Wstaw

| Skrót | Działanie |
|---|---|
| `Ctrl+Shift+F` | Wstaw wzór |

## Widok

| Skrót | Działanie |
|---|---|
| `Ctrl+Shift+M` | Widok źródła |
| `Ctrl+Shift+D` | Widok podzielony |
| `F11` | Tryb bez rozproszeń (ESC, aby wyjść) |
| `F9` | Konspekt |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Powiększenie (także Ctrl + kółko) |

## Pomoc

| Skrót | Działanie |
|---|---|
| `F1` | Podręcznik |
