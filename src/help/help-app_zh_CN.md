# 使用手册

**md-editor** 是一款所见即所得（WYSIWYG）的 Markdown 编辑器：你直接在渲染好的文本
上输入和设置格式，看不到那些符号。保存时，文档会重新序列化为纯 Markdown。

## 打开与保存

- **文件 → 新建**（Ctrl+N）在新标签页中创建一个空白文档。
- **文件 → 从模板新建**用一份现成的骨架创建文档，填空即可。模板按类别分组（个人与
  通用、编程、教学、商务、写作…）。
- **保存为模板…**把当前文档保存为你自己的模板（含名称和类别），它会和内置模板一起
  出现在上面那个菜单里。该菜单末尾的**管理模板…**可以编辑或删除它们。
- **文件 → 打开…**（Ctrl+O）打开已有的 `.md` 文件。程序会在**文件 → 打开最近的
  文件**中记住最近打开过的文档。
- **文件 → 导入**把其他格式的文档转换成 Markdown，在一个未命名的新标签页中打开
  （不会改动原文件）：**从 HTML 导入…**（网页）、**从 EPUB 导入…**（电子书，按顺序
  读取各章）以及**其他格式（Pandoc）…**（DOCX、ODT、RTF、LaTeX、reStructuredText…，
  需已安装 Pandoc）。内容越简单，转换效果越好；程序会遵循文件声明的字符集。
- **保存**（Ctrl+S）和**另存为…**（Ctrl+Shift+S）以 UTF-8 写入文档。**打开所在
  文件夹**会在文件管理器中打开当前文档所在的文件夹。
- **还原为已保存的版本**放弃未保存的更改，并从磁盘重新加载文件（会先请你确认）。
  只有当文档已有对应文件且存在未保存的更改时才可用。
- 如果文件在编辑器之外被改动，程序会检测到：若你没有未保存的更改，就直接重新加载；
  若有，则询问你要怎么做。
- 你也可以把文件**拖放**到窗口上来打开它。

### 标签页（多个文档）

你可以同时打开多个文档，每个文档占一个**标签页**：

- **新建**（Ctrl+N）、**从模板新建**和**打开**（Ctrl+O）都会创建一个标签页（如果
  最初的空白标签页还空着，就复用它）。把文件拖放进来同样会在标签页中打开；如果它
  已经打开，就跳到它所在的标签页。
- 单击标签页即可切换文档，拖动标签页可以重新排序。用键盘时，**Ctrl+PgDn /
  Ctrl+PgUp**（或 **Ctrl+Tab / Ctrl+Shift+Tab**）切换到下一个或上一个标签页。
- **关闭标签页**（Ctrl+W）关闭当前标签页；如果有未保存的更改，会先询问。最后一个
  标签页不会被关掉，而是变成一个新文档。
- **重新打开已关闭的标签页**（Ctrl+Shift+R）重新打开你最近关掉的标签页（仅限磁盘上
  有对应文件的那些）。
- 标签上显示文件名；若有未保存的更改，还会显示一个圆点（•）。
- 在标签页上**单击右键**可以选择**打开所在文件夹**、**复制文件名**和**复制完整
  路径**。
- 关闭程序时会记住打开着的文档，下次启动时全部重新打开。

### *Front matter*

如果文档以 `---…---`（YAML）或 `+++…+++`（TOML）块开头，保存时会原样保留：它在编辑器
里看不到，也不参与编辑。它用来存放 `title`、`lang` 等元数据，导出时会用到。

## 设置文本格式

选中一段文字，然后用工具栏或**格式**菜单设置格式：

- **粗体**（Ctrl+B）、**斜体**（Ctrl+I）、**下划线**（Ctrl+U）、**删除线**
  （Ctrl+Shift+X）。
- **行内代码**（Ctrl+E），用于 `等宽` 的小段文字。
- **链接**（Ctrl+K）：在选区上加上 `[文字](网址)`。
- **高亮**（Ctrl+Shift+H）：把选区包进 `==标记==`，文字会显示为带高亮底色。由于 `==`
  不是标准 Markdown 语法，它会按字面文本保存。
- **上标**（Ctrl+Shift++）和**下标**（Ctrl+Shift+-）：把选中的文字升高或降低；保存
  为 `^文字^` 和 `~文字~`（Pandoc 风格）。

工具栏上的按钮会反映光标处当前生效的格式。

**自动配对。**输入 `(`、`[`、`{` 或 `` ` `` 时，另一半会自动补上，光标停在中间；如果
有选中的文字，就把它包起来。若你在配对符号的正前方输入右半边，编辑器会“跳过”它，而
不是再插入一个。

**输入规则。**在一行开头输入 Markdown 的块级标记再加一个空格，就会就地转换成对应格式
（标记本身不会留下）：`#` … `######` + 空格 → 一级到六级标题；`>` → 引用；`-`、`*`
或 `+` → 项目符号列表；`1.`（或 `1)`）→ 编号列表。效果与用工具栏设置完全一样。

## 标题、列表与块

- **标题** H1–H6：在**格式 → 标题**中选择，或按 Ctrl+1 … Ctrl+6。用
  Ctrl+Shift+[ / Ctrl+Shift+] 可以把光标所在的标题**提升／降低**一级。
- **列表**：项目符号（Ctrl+Shift+U）、编号（Ctrl+Shift+O）和任务（Ctrl+Shift+T，带
  复选框）。在某一项的末尾按 Enter 会自动创建下一项；在空白项上按 Enter 则退出列表。
  **单击复选框**即可勾选或取消勾选任务。
- **引用**（Ctrl+Shift+Q，或在段首输入 `>`）和**代码块**（Ctrl+Shift+K）都可以从工具栏
  设置；两者都能正确地往返转换回 Markdown。把光标放在代码块内，用**格式 → 代码块
  语言…**指定它的语言，即可获得语法高亮。
- 把**鼠标移到**代码块上时，右上角会出现它的**语言**（单击可更改）和一个**复制**代码的按钮。
- **缩进**：**格式 → 增加／减少缩进**（Ctrl+] / Ctrl+[）用来嵌套列表和引用。

## 转换文本与剪贴板

- **编辑 → 转换文本**改变字母的大小写：**全部大写**、**全部小写**和**首字母大写**。
  它作用于选区；若没有选区，则作用于光标所在的那个单词。
- **编辑 → 行排序**把选中的若干行按字母顺序排序。这一项必须先选中文本：没有选区
  时它什么也不做。
- 同一菜单中的**智能排版**会在选区内把 `--`/`---` 转换为 `–`/`—`，把 `...` 转换为
  `…`，并根据上下文把直引号换成弯引号。
- **粘贴为纯文本**（Ctrl+Shift+V）不带格式粘贴。**粘贴为 Markdown**（Ctrl+Alt+V）
  把剪贴板中的富文本内容（HTML）转换成 Markdown，而不是照搬来源的格式。
- **复制为 HTML** 把选区（或整个文档）复制为 HTML，方便粘贴到邮件、CMS 等处。
- **复制为 Markdown** 把选区（或整个文档）复制为 Markdown 文本，方便粘贴到别的
  Markdown 编辑器或代码输入框里。
- 在选中的文字上粘贴**网址**时，这段文字会自动变成链接。
- **编辑 → 整理 Markdown** 一次性规范整个文档：把项目符号统一为 `-`，去掉每行末尾的
  空格，合并多余的空行，并调整标题 `#` 之后的空格。它很保守：不会改动代码块内部的
  内容。

## 链接与图片

- **插入 → 链接…**打开一个填写文字和网址的对话框。如果之前有选区，它会作为文字带入。
- **Ctrl+单击**链接会用系统浏览器打开它；鼠标悬停时，光标旁的提示和状态栏都会显示
  该网址。
- **插入 → 图片…**会询问替代文字和文件路径（也可以填网址）。如果文档已经保存过，
  路径会写成相对于该 `.md` 的**相对路径**，以便文档整体搬动。
- 从剪贴板**粘贴图片**（Ctrl+V，或**插入 → 粘贴图片**）会把图片以 PNG 保存在 `.md`
  旁边，并插入 `![替代文字](相对路径)`，而不是内嵌进文档：这样它才能在往返转换为
  Markdown 时保住（内嵌的图片则不行）。
- 把图片文件拖到窗口上**不会**插入图片：它和其他文件一样，会在标签页中打开。

## 脚注

- **插入 → 脚注**（Ctrl+Shift+N）在光标处插入编号引用标记 `[^n]`，并在文档末尾创建
  对应的定义 `[^n]:`，等你写上注文。
- 引用标记显示为**上标**；**单击**其中一个，光标就会跳到它的定义处。
- 它们按标准 Markdown 保存（正文里是 `文字[^1]`，下方是 `[^1]: 注文`），所以与其他
  编辑器兼容。

## 警示块、符号与文本快捷输入

- **插入 → 警示块**创建 GitHub 风格的醒目提示块：首行为 `[!NOTE]`、`[!TIP]`、
  `[!IMPORTANT]`、`[!WARNING]` 或 `[!CAUTION]` 的引用块。它显示为带底色的方块和彩色
  标题，并保存为与 GitHub 兼容的 Markdown。
- **插入 → 水平分隔线**在块与块之间插入一条分隔线（Markdown 里的 `---`）。
- **插入 → 特殊符号…**打开按类别分组的字符映射表（数学、希腊字母、箭头、货币、
  标点…）；单击即可插入符号，对话框会保持打开，方便连续插入多个。
- **`:名称:` 快捷输入**：输入 `:alpha:` 或 `:euro:` 之类的代码，就会展开成相应的
  符号（α、€…）。
- **插入 → 日期**和**日期和时间**按本地格式插入当前的日期（和时间）。

## 代码片段（可重复使用的文本块）

**代码片段**就是一小段 Markdown，你给它起个名字存起来，以后点两下就能插入：一段
署名、一个表格模板、一条常用的提示…

- **插入 → 代码片段**会列出你已有的片段；选中一个，它的内容就会插入到光标处（在源
  代码视图里同样有效）。
- **插入 → 代码片段 → 管理代码片段…**打开一个对话框，用来新建、编辑和删除你的片段。
  每个片段都有一个**名称**（就是菜单里显示的那个）和一段 Markdown **内容**。
- 它们保存在程序的设置里，因此在你所有的文档中都能用，不限于当前这一个。

## 表格

- 当光标**位于表格内**时，表格上方会出现一个**浮动工具栏**，带有插入／删除行列和设置列对齐方式的按钮。
- **Tab** 跳到下一个单元格，**Shift+Tab** 跳到上一个；在最后一个单元格里按 **Tab** 会新增一行。
- **插入 → 表格…**会询问行数和列数，并在光标处创建表格。
- **插入 → 从剪贴板插入表格**把从电子表格或 CSV 文件里复制来的 TSV/CSV 数据（以制表符
  或逗号分隔的列）转换成表格。
- **表格**菜单中的各项操作（增删行列、列对齐方式、按列排序各行）只有当光标位于表格
  内时才会启用。
- 列的对齐方式（左／中／右）在保存时会以 `:--`/`:-:`/`--:` 保留下来。
- **表格 → 按列排序各行**（升序／降序）按光标所在的那一列重新排列各行，表头保持不动；
  程序会自动判断该列是数字还是文本。

## 数学公式

md-editor 支持行内（`$...$`）和块级（`$$...$$`）的 **TeX 公式**，语法就是 LaTeX 的
惯常写法（Pandoc、Obsidian、Quarto…）。不需要任何外部依赖。

- **插入 → 公式…**（Ctrl+Shift+F）打开一个对话框，其中有输入 TeX 的字段和**实时
  预览**：边写就能边看到效果。选择*行内*或*块级*，确认即可插入。
- 公式会以**真正的二维**方式排版：分式（`\frac`）上下叠放并带分数线，大型运算符
  （`\sum`、`\int`、`\prod`…）的上下限显示在上方和下方，根式（`\sqrt`）带有根号线，
  还支持矩阵（`\begin{pmatrix}`…）、二项式系数（`\binom`）和重音符号（`\hat`、
  `\vec`、`\bar`…）。较简单的（幂、下标、希腊字母）则直接排在行内。公式会随缩放
  一起放大缩小。
- **双击**一个公式，会重新打开对话框并载入它原来的 TeX：编辑后确认即可替换。
- 公式是**原子性**的：如果你在公式内部输入，程序会提醒你改用双击；在其边缘按
  Backspace/Delete 会删掉整个公式。
- **导出**时公式会被保留：导出为 LaTeX 时原样写出（前导部分会带上 `amsmath` 和
  `amssymb`）；导出为 HTML/PDF/ODF 时，写成它们的行内近似形式。
- 在**源代码视图**里，它们显示为 `$...$` / `$$...$$`，保存时所有 TeX 字符
  （`\sum`、`\frac`、`_`、`*`）都完好无损。

例如：

```
能量是 $E = mc^2$。

$$
\sum_{i=1}^n a_i = \frac{n(n+1)}{2}
$$
```

> 在源代码里，`$$...$$` 可以跨多行（Obsidian/Pandoc 风格）；`$...$` 则必须在同一行内
> 开始和结束。

## 图表

语言为 `mermaid` 或 `plantuml` 的代码块，会在块的正下方**预览为图片**，既不改动代码
（它仍然可以编辑），也不改动保存下来的 Markdown。

- 需要事先安装相应的工具：PlantUML 需要 **`plantuml`**（以及 Java），Mermaid 需要
  **`mmdc`**（mermaid-cli，以及 Node）。
- 如果缺少该工具，块下方会出现一条提示，给出适用于你操作系统的安装命令；代码块本身
  保持不变。
- 图片只是显示效果：它不会写进 Markdown，也不算作未保存的更改。
- **视图 → 预览图表**可以开启或关闭这项自动预览（默认开启）。如果你更愿意让这些块
  保持为代码，就把它关掉 —— 比如你已经自己在块下方插入了预先渲染好的图片，不想看到
  两份。

举个例子：一个带 `mermaid` 标签、内容为 `flowchart LR  A --> B --> C` 的代码块，会
预览为相应的流程图。

## 拼写检查

- 按**文档语言**（依次取自 front matter 的 `lang`、语言设置或系统）给拼写错误的单词
  加上红色下划线。代码、公式和链接不在检查之列。
- 在带下划线的单词上**单击右键**会给出**建议**（单击即可替换）、**加入词典**（个人
  词表，长期有效）和**忽略**（仅本次会话有效）。
- 在**视图 → 拼写检查**中开启或关闭，在**视图 → 拼写检查语言**中指定语言（也可以
  保持自动）。
- 它需要 Hunspell 词典：在 Linux 上用系统的词典（`hunspell-es`、`hunspell-en-us`…），
  在 Windows/macOS 上则随程序一起提供。

## 查找与替换

- **查找**（Ctrl+F）在底部打开一个工具条，其中有查找和替换的输入框以及若干选项
  （大小写、全字匹配、正则）。**替换…**（Ctrl+H）打开同一个工具条，并把焦点放在替换
  框里。按 Esc 关闭。
- **查找下一个**（F3）和**查找上一个**（Shift+F3）重复上一次查找，不必回到工具条，
  即使它已经关闭也一样；如果你还没查找过任何内容，F3 会打开工具条。查找到末尾时会
  绕回开头继续。
- 工具条会高亮文档中**所有**匹配项，并显示一个**「第 N / M 个」**计数（你在第几个
  匹配项、一共几个）。**全部替换**一次性替换所有匹配项。

## 文档大纲

左侧的面板显示标题目录（TOC）：它随着你输入而更新；单击其中一项，光标就会跳到那个
标题。用 F9 显示或隐藏它。按 **F6** 可以把键盘焦点移到大纲上（若它原本是隐藏的，会
先显示出来）；在那里，方向键可以在标题间移动，按 **Enter** 跳到选中的标题并把焦点交
还给编辑器。再按一次 **F6** 则直接把焦点还给编辑器。

面板顶部的**筛选框**只显示与你输入内容相符的标题（以及它们的上级）；**⊞/⊟** 两个
按钮可以全部展开或全部折叠。你手动折叠的状态会一直**保留**，即使继续编辑文档也不会
丢失。

你还可以**拖动**大纲中的某一项，把那一节 —— 它的标题、内容和各个子节 —— 在文档中
**重新排序**，且不改变其级别。此外，**插入 → 目录 (TOC)** 会把由文档标题构成的嵌套
列表写进文档。**视图 → 跳转到标题…**（Ctrl+G）通过输入标题的部分文字跳到该标题，
**跳转到行…**（Ctrl+L）把光标带到指定行号（在源代码视图中，即 Markdown 的行号）。
**命令面板**（Ctrl+Shift+P）通过输入名称的一部分来查找并执行菜单中的任意操作。

## 文档统计

- **视图 → 文档统计…**显示词数、字符数（含空格与不含空格）、段落数、句数和预计阅读
  时间（针对整个文档或选区）。
- **视图 → 显示字数统计**在状态栏中开启一个常驻的计数。
- **视图 → 显示行号和列号**在状态栏中显示光标的位置（行和列）。

## 无干扰模式

**视图 → 无干扰模式**（F11）进入全屏，隐藏菜单和各个工具栏，文本居中排成一个便于
阅读的窄栏。大纲面板如果是显示状态，会紧贴在中央区块旁边。按 Esc 或 F11 退出。

## 专注模式

**视图 → 专注模式**（F12）帮助你专注于正在写的内容，而且不必离开普通窗口。一个开关
同时启用两件事：

- **打字机效果**：光标所在的行始终保持在垂直方向的中间。你输入时，文本会随之滚动，
  让当前行停在屏幕中部，而不是越写越贴近下边缘。
- **淡化**：除了光标所在的那一段之外，整个文档都会变暗，只有当前段落清晰醒目。

它在所见即所得编辑器和源代码视图中都有效，并且与无干扰模式（F11）**互相独立**：两者
可以同时使用，也可以各用各的。

## 源代码视图

**视图 → Markdown 源代码**（Ctrl+Shift+M）在所见即所得编辑器和全屏的纯文本编辑器
（显示原始 Markdown）之间切换。在源代码模式下所做的修改，会在切回可视模式时写入
文档。

**视图 → 分屏视图**（Ctrl+Shift+D）把两者并排显示：左边是所见即所得编辑器，右边是
源代码，二者保持同步（在一边输入的内容会反映到另一边）。它与全屏的源代码模式互斥。

在源代码视图中，还有一些针对光标所在行的**行命令**快捷键：**Alt+↑ / Alt+↓** 把该行
上移／下移，**Ctrl+D** 复制该行，**Ctrl+Shift+K** 删除该行，**Ctrl+J** 把它与下一行
合并。

## 导出与打印

**文件 → 导出**提供 **PDF**、**HTML**、**ODF (.odt)**、**DOCX (.docx)**、
**LaTeX (.tex)**、**EPUB (.epub)** 和**纯文本 (.txt)**。导出为 ODF、DOCX、LaTeX 和
EPUB 时会嵌入文档语言（依次取自 front matter 的 `lang`/`language`、程序的设置，最后
才是系统语言）。导出为 **PDF** 时，若 front matter 中有标题和作者（`title`、
`author`），也会一并嵌入。

你还可以**仅把选中的内容导出为 PDF**，并使用**打印预览**。

**文件 → 打印**（Ctrl+P）打开系统的打印对话框；**打印所选内容**只打印选中的部分。

**视图 → 打印时显示页码**（默认开启）会在打印和导出为 PDF 时在页脚加上页码
（`N / M`）。

## 主题与外观

- **编辑 → 首选项…**（Ctrl+,）把最常用的设置（主题、暖光、行距、高亮当前行、专注模式、页码）汇总在一个带标签页的对话框里。
- **视图 → 主题**提供浅色、深色、GitHub Light、GitHub Dark、Monokai、高对比度、
  Solarized Light 和 Solarized Dark。**跟随系统**会让浅色／深色主题与操作系统保持
  一致。
- **视图 → 夜间暖光**按当前时间减弱背景中的蓝色成分。
- **视图 → 行距**调整编辑器的行高：单倍、1.5 倍或双倍。
- **视图 → 高亮当前行**用淡淡的背景色标出光标所在的行。
- **缩放**：Ctrl+鼠标滚轮、Ctrl++ / Ctrl+- 以及**恢复默认字号**（Ctrl+0）会缩放整个
  界面（不只是编辑器里的文字）。
- **视图 → 语言**更改界面语言，立即生效（会重建窗口）。

## 自动恢复

在你编辑的过程中，内容每隔几秒就会自动保存到一份草稿副本里。如果程序异常退出，下次
打开时会提示你恢复当时正在写的内容。

## 无障碍功能

- **屏幕阅读器**：编辑器、大纲面板、查找输入框以及其他控件都有无障碍名称；此外，状态消息（已保存、「未找到」、磁盘上的变动…）也会朗读出来。
- **纯键盘操作**：所有操作都有快捷键或菜单项（按 F10 或 Alt 打开菜单栏）。参见[快捷键](#快捷键)一览表。
- **对比度与字号**：**高对比度**主题和整个界面的**缩放**对低视力有帮助；起始字号取自系统设置。
- **焦点**：获得焦点的元素会用当前主题的选中色高亮显示。
